# 需求文档

**产品名称：** AI Workspace  
**版本：** v1（个人使用）  
**平台：** Mac 优先（Tauri 跨平台，本版按 macOS 验收）  
**状态：** 已实现

## 1. 背景

日常需要同时使用多个 AI 网站（ChatGPT、Gemini、Claude、DeepSeek、Grok 等）。浏览器里标签过多、窗口分散，切换成本高。

希望用一个桌面 App 把这些网站收进同一窗口：左侧选服务，右侧看完整网页。

## 2. 目标用户

个人使用者，本机单用户。不做账号体系、不做多人协作、不做分发运营。

## 3. 要解决的问题

- 多个 AI 网站需要同时使用。
- 浏览器标签页过多、切换麻烦。
- 不希望每个 AI 单独打开浏览器窗口。
- 登录态需要在 App 内持久化：每个站点在 App 里登录一次，重启后仍保持。

**明确放弃：** 复用 Microsoft Edge 中已有的登录状态。Mac 上 Tauri 使用系统 WKWebView，与 Edge Cookie 隔离，v1 不导入浏览器 Cookie。

## 4. 产品形态

单窗口、左右布局。点击左侧把服务放到当前焦点栏；也可把右侧分成最多 3 栏，同时看多个网页。不新开 Mac 窗口。

```
┌──────────────────────────────────────────────────────────┐
│                      AI Workspace                        │
├──────────────┬────────────────────┬──────────────────────┤
│              │ ← → ↻ [ChatGPT] ⊞  │ ← → ↻ [Claude] ⊞ ✕  │
│  ◎ ChatGPT   ├────────────────────┼──────────────────────┤
│  ◎ Gemini    │                    │                      │
│  ◎ Claude    │   Web 页面 A       │    Web 页面 B        │
│  ◎ DeepSeek  │                    │                      │
│  ◎ Grok      │                    │                      │
│  管理        │                    │                      │
└──────────────┴────────────────────┴──────────────────────┘
```

- 左侧：AI 服务列表（图标 + 名称），宽度约 240px。下方可固定分屏组合，点击即恢复。

- 右侧每一栏顶部：该栏服务的页面标签，以及后退 / 前进 / 刷新、分屏、关闭分屏。
- 右侧其余：各栏当前标签对应网站的完整 Web 页面，可左右并排。
- 窗口标题栏使用 macOS Overlay，红绿灯位于侧栏左上。

## 5. 功能需求

### 5.1 内置服务

侧栏默认显示以下入口（完整内置目录以 `src/types.ts` 的 `CATALOG_SERVICES` 为准，图标来自 Cherry Studio 小程序品牌资源）：

| 服务 | 地址 |
| --- | --- |
| ChatGPT | https://chatgpt.com |
| Gemini | https://gemini.google.com/app |
| Claude | https://claude.ai |
| DeepSeek | https://chat.deepseek.com |
| Grok | https://grok.com |

目录中还有 Kimi、通义千问、豆包、腾讯元宝、Perplexity 等站点，可在「管理」页加入侧栏。每个内置项带品牌图标与名称。


### 5.2 服务切换

- 点击列表项后，把该服务放到当前焦点栏；若已在某一栏中，则聚焦该栏。
- 每个服务独立页面实例：切走再切回时，当前对话尽量仍在（不销毁页面）。
- 首次进入某服务时再加载，避免启动时一次性打开全部站点。

### 5.3 登录与会话

- 用户在右侧网页内完成各站点自己的登录流程。
- Cookie / 站点本地存储由系统 WebView 持久化，进程退出后仍有效。
- OAuth、`window.open` 或 `target=_blank` 在当前服务下新开标签页，不新开 App 窗口。首页标签不可关；额外标签可关。

### 5.4 服务管理与添加

- 侧栏底部「管理」打开启动台式管理页（参考 Cherry Studio 小程序页）：图标网格、搜索、添加。
- 打开管理页时隐藏全部内容 WebView，避免弹层被原生网页盖住。关闭后恢复各栏网页。
- 点目录项：未在侧栏则加入并打开；已在侧栏则直接打开。悬停可把内置项移出侧栏（至少保留一项）。
- 「添加服务」填写名称、http(s) URL，可上传图标（小于 200KB）。仅自定义项可编辑 / 删除。
- 内置目录以产品代码为准；侧栏显示哪些内置项记在本地。

### 5.5 状态记忆

- 记住上次选中的服务，下次启动聚焦该项所在栏。
- 记住分屏栏数、各栏对应服务和宽度比例。
- 记住固定到侧栏的分屏组合、当前打开的分屏菜单，以及是否锁定。
- 记住用户添加的自定义服务列表。
- 记住侧栏里启用了哪些内置服务。
- 内置服务目录以产品代码为准，不因本地缓存而丢失更新。


### 5.6 窗口与布局

- 默认约 1280×840，最小约 960×640，可缩放。
- 缩放时各栏网页铺满各自剩余区域，不遮挡侧栏、标签栏和分屏分隔条，不露出空隙。

### 5.7 页面导航

- 每一栏标签栏左侧提供后退、前进、刷新，只作用于该栏当前标签。
- 后退 / 前进使用该内容 WebView 自己的浏览历史（含站点内 `history.pushState`）。
- 没有对应历史时，后退 / 前进按钮禁用。
- 刷新重新加载当前 URL，不销毁 WebView，登录态与页面实例保留。

### 5.8 页面标签

- 每个服务至少有一个首页标签，标题为服务名，不可关闭。
- `window.open` / `target=_blank` 打开的 http(s) 页面，作为该服务的额外标签。
- 标签显示页面标题；同一 URL 已打开则切到已有标签。
- 单个服务最多 8 个标签；超出时复用最近一个可关闭标签。
- 切换左侧服务时，右侧当前焦点栏显示该服务的标签，并回到该服务上次选中的标签。若该服务已在某一栏中，则聚焦该栏，不重复打开。

### 5.9 多网页分屏

- 每栏是独立的原生子 WebView，左右并排，最多 3 栏。
- 标签栏「向右分屏」在焦点栏右侧插入一栏，放入列表中尚未显示的下一个服务；拖动栏间分隔条可改宽度。
- 侧栏中未显示的服务，悬停可「分屏打开」；⌘/Ctrl + 点击同样在新栏打开。已显示的服务再点一次只聚焦对应栏。
- 同一服务同一时刻只出现在一栏。超过 3 栏或没有可显示的新服务时，分屏按钮不可用。
- 栏数大于 1 时可关闭某一栏，其余栏自动铺满。重启后恢复各栏服务与宽度比例。
- 「固定当前分屏」把当前 2～3 栏组合写到侧栏「分屏」菜单，下次点该项即恢复，不必重新分屏。最多 12 个；名称由各栏服务名组成。
- 分屏可锁定：锁定后这份菜单里的网页不能改（不能分屏、关栏、把别的服务塞进各栏）。点侧栏其他服务会离开当前分屏、进入该页面；再点该分屏菜单即可回来。解锁后点其他服务会改当前分屏各栏网页。拖动分隔条改宽度始终允许。锁定状态随该分屏菜单一起记住。

## 6. 非功能需求

- 内容区必须是完整网站，交互、登录、对话由该网站自己提供。
- 不能用 iframe 套站点（会被 `X-Frame-Options` 等拦截）。
- 第三方网页不得调用本 App 的本地存储或 Rust 命令。
- v1 以文字对话为主；语音、验证码、Chrome 专有能力不做保证。

## 7. 非目标（v1 不做）

- 从 Edge / Safari 导入 Cookie 或登录态
- 多窗口、上下分屏、同一服务同时出现在两栏
- 同一站点多账号配置文件
- 浏览器扩展
- 语音 / 麦克风权限专项适配
- Windows / Linux 体验打磨（代码可编译，验收以 Mac 为准）

## 8. 验收标准

1. 启动后进入上次使用的服务（或列表第一项），右侧为该站点完整页面。
2. 在 A 站点登录后切到 B 再切回 A，登录与当前对话仍在。
3. 完全退出 App 再打开，登录态仍在。
4. 添加自定义 https 站点后可打开，删除后列表与页面临时实例消失。管理页能搜索、从目录加入侧栏、移出内置项；侧栏显示图标和名称。

5. 拉伸窗口时各栏网页跟随铺满，不与侧栏、顶部标签栏或分屏分隔条重叠。
6. 全程只有一个 Mac 窗口（`window.open` / `target=_blank` / 登录跳转也不另开窗口）。
7. 内容页内跳转可后退；`target=_blank` 会多出一个可关闭标签；刷新后仍停留在当前服务。
8. 没有后退 / 前进历史时，对应按钮不可点。
9. 右侧顶部能看到当前栏的标签，点标签可切换，额外标签可关闭。
10. 点分屏后能同时看到两个不同 AI 网页；拖动分隔条改宽度；关闭一栏后另一栏铺满。
11. 退出后再打开，分屏栏数、各栏服务和宽度比例仍在。
12. 把当前分屏固定到侧栏后，退出再打开仍能点该项恢复。锁定后点其他服务会进入该页面，再点分屏菜单能回来；解锁后可以改各栏网页。

验收必须在桌面 App（`pnpm tauri dev`）中进行，不能用浏览器打开 Vite 开发页代替。
